Sign in, Create account & Forgot password

Three switchable concepts. Every state is a working modal/page — click through them, toggle the theme, resize. Copy is taken verbatim from your current modals.

Changes applied to all concepts: the Data Privacy box now appears only on Create account (it's a decision, not a login concern); reset copy no longer confirms whether an email exists; fields carry real autocomplete attributes; errors show inline per field. All owl art and tokens follow the design system.
Concept A — Recommended. A fixed-maroon brand panel does the emotional work (owl + the hero line you already use), so the modal feels like ReviewTayo instead of a generic login. Sign in / Create account merge into one surface with a switcher; Forgot password is an inline state, not a third modal. On phones it docks as a bottom sheet and the panel collapses to a slim header.
Concept B. The lightest option: one compact card, tab switcher, inline reset — same footprint as your current modal, so it drops into the existing landing page with zero layout changes. Same bottom-sheet behavior on mobile. Choose this if you want minimal change, A if you want the brand moment.
Concept C. A standalone page for places a modal can't go: reset-password links from email (arrive with no page context) and a dedicated /signin route. Full-height split layout; the chips above the form let you preview all five auth states.
